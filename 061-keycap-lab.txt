==================== PROMPT ====================
Design a mechanical-keyboard playground, "Keycap Lab". A compact tenkeyless-style keyboard in HTML/CSS with convincing 3D-ish keycaps (each key: a base with a slightly smaller top surface, gradient lighting, inner shadow, legend text; staggered rows with a sculpted profile via skew and box-shadows; a spring-like press animation) on a felt desk mat (gradients plus noise) with soft ambient shadows; a case with a brass plate and RGB underglow (soft coloured glow beneath the keys with selectable breathe / wave effects). Real typing: physical key events press the matching keys, and a paper card "notepad" below shows what you type; tapping virtual keys works too. Sound (starts after the first key press, with a mute toggle): synthesised "thock / clack / creamy" switch sounds via WebAudio (a short filtered noise burst plus a resonant sine drop, slight random detune per key), a space-bar thud and an enter ding. Colourway themes via swatch buttons, each restyling the keycaps with an animated transition: "Botanical" (forest green, cream, copper), "1984 Beige" (retro beige, grey, blue accents), "Miami" (pastel pink, cyan, white), "Nocturne" (black and gold), "Bento" (pastel with matcha). A "Typing test" mini mode shows a short sentence and measures WPM and accuracy live. Page chrome stays neutral warm grey #cfc9bf with theme accents. Type: rounded/geometric sans legends, mono UI. On mobile show a compact virtual layout.

TECHNICAL REQUIREMENTS: Deliver one completely self-contained, standalone HTML5 file with all CSS inline in a <style> tag and all JavaScript inline in a <script> tag. No external dependencies of any kind: no CDN, no external fonts (system font stacks only), no external images, no external SVG files, no libraries, no network requests. It must work by simply opening the file in a browser, fully offline. It must be responsive from 360px phones to large desktops, validate as standard HTML5, respect prefers-reduced-motion, support mouse and touch input, and run without console errors. Hand-craft it as a premium, award-worthy piece of digital art with real, evocative copy (no lorem ipsum), a disciplined palette, careful typography, polished motion and delightful details.

==================== TITLE ====================
Keycap Lab

==================== DESCRIPTION ====================
A tactile keyboard bench on a warm grey page. An 87-key tenkeyless board sits in a machined case with a brushed brass plate, screws, a knurled volume knob and Caps/Audio LEDs, resting on a stitched felt desk mat lit by a coloured underglow. Every keycap is built from a sculpted top face, a darker skirt, a contact shadow and a legend set in a rounded geometric sans, with homing bars on F and J. Five colourways (Botanical, 1984 Beige, Miami, Nocturne, Bento) repaint the caps in a left-to-right wave while the mat, case, tape and accents cross-fade. A paper index card under the board shows whatever you type (a self-typing greeting plays until you touch anything) and flips into a typing test with live WPM, accuracy and a best score. Switch sounds (thock, clack, creamy), a space-bar thud and an enter ding are synthesised live with WebAudio after the first key press. On phones the board becomes a compact thumb layout with the card above it.

==================== TECHNIQUES ====================
- CSS-only keycaps: skirt + inset top face with layered radial and linear gradients, inset highlights, per-row perspective tilt (rotateX) for a sculpted profile, contact shadows that fade as a key sinks
- Spring physics in JS (semi-implicit Euler, fixed sub-steps) driving a --d CSS variable: a firm press with a bottom-out bounce and a softer, bouncier release
- Colour tokens (--cap, --lg, --mat, --case, --accent) registered with CSS.registerProperty so colourway changes animate; each key carries its own transition-delay derived from x/y for a sweeping repaint
- color-mix() used for caps, skirts, plate and case shading so one palette token drives every tone
- Felt, paper and page grain drawn once on tiny canvases (noise plus fibres) and used as data-URL backgrounds with blend modes on static layers
- Underglow: a low-resolution canvas of one soft radial blob per key (breathe, wave, ripple, off) upscaled by the browser, plus a compositor-animated CSS halo (stacked blurred shadows and sweeping blobs) on the desk mat
- WebAudio switch synth: filtered white/brown noise bursts plus pitch-dropping sine or triangle thumps per profile, key-position pitch and random detune, key-up ticks, a multi-partial bell for Enter, a low thud with stabiliser rattle for Space, compressor limiting and master gain capped below 0.25
- Two layouts built from data arrays: 87-key ANSI TKL and a 10-column compact thumb layout that swaps at 939px
- Pointer Events with multi-touch key presses, latching virtual Shift and Caps, and physical KeyboardEvent.code mapping with AltGr-safe shortcuts and Tab left free for navigation
- Typing test with per-character states, net WPM, keystroke accuracy, progress bar and best score kept in localStorage (try/catch)
- Roving radio groups, tablist keyboard support, focus-visible rings, aria-pressed sound toggle, slider role on the knob, reduced-motion fallbacks

==================== INTERACTION ====================
Type anywhere on a physical keyboard: the matching keycap sinks with a springy press, lights the underglow around it and appears on the notepad (Enter, Backspace and Space work; Tab and Esc are left for navigation and the typing test). Tap or click the on-screen keys, including multi-finger taps and a latching Shift or Caps. Sound wakes on the first key press or tap; the Sound pill mutes it and the brass knob on the case sets volume by dragging, mouse wheel or arrow keys. Choose a colourway with the five swatches, a switch sound (Thock, Clack, Creamy) and an underglow mode (Breathe, Wave, Ripple, Off) from the deck; radio groups respond to arrow keys. The card tabs switch between Notepad and Typing test; in the test, type the sentence shown, Backspace to correct, Esc or Enter for a new one. Secret words typed on the notepad (thock, clack, creamy, brass) switch the sound set or flash the plate. Below 940px the compact layout appears with the card above the keyboard. With prefers-reduced-motion the key drop-in, idle underglow motion, caret blinking and spring bounce are removed while the page keeps its static glow and full functionality.
