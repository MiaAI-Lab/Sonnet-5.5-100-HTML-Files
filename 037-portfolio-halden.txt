==================== TITLE ====================
Halden & Vesper Portfolio

==================== DESCRIPTION ====================
A single-page portfolio for the fictional Oslo/Lisbon design studio Halden & Vesper, built in a strict four-colour palette (bone #ecebe6, ink #0d0d0d, electric vermilion #ff4b1f, soft grey #bdbab2) and set entirely in heavy system grotesques and mono captions. A loader counts up in giant vermilion numerals and lifts like a shutter to reveal a hero where the studio name (HALDEN / & VESPER, ampersand in vermilion) is fitted edge to edge and every letter swells, thickens and pulls its neighbours tighter as the pointer approaches, while a ghost pointer drifts across the type when nobody is touching it. Below sit a tilted vermilion marquee ("Available for select projects — 2026"), a split-text studio statement with a rotating circular badge, practice columns and counting figures, and a giant six-row project index: hovering a row fills it with ink, dims the rest and floats a canvas-drawn generative artwork on the cursor, skewing with velocity; clicking runs a vermilion curtain wipe into a full-screen case study with oversized numerals, giant title, a large live artwork, metadata, short copy, big statistics and a next-project link. A client quote, an ink footer with a magnetic "Get in touch" disc and a huge letter-rolling email-style link (hello@halden.example, fictional) close the page. An ink/bone mode toggle, a grain tile, a live Oslo clock, an auto-hiding header and a hidden dachshund named Kern add personality.

==================== TECHNIQUES ====================
- Per-letter proximity typography: every hero glyph is a separately transformed span; canvas measureText supplies real ink bounds, cap height and baseline, so each row is fitted exactly edge to edge. Pointer distance (gaussian falloff, elliptical) drives scaleX (width), a dynamic -webkit-text-stroke (approximate weight) and per-gap tracking, then all widths are renormalised so the line always fills the container; vertical scale adapts to viewport height.
- Idle "ghost pointer" (Lissajous path) keeps the type breathing on touch screens and when the mouse rests; letters rise from masked lines on intro.
- Custom cursor: white disc with mix-blend-mode: difference, damped follow, grows over links and becomes a 108px disc reading VIEW / CLOSE / NEXT / COPY over labelled targets; switches to a solid ink disc on vermilion surfaces to avoid off-palette inversion.
- Six generative canvas artworks driven by Perlin noise and trigonometry: wobbly noise-displaced rings around a waning moon (Nocturne), an animated ellipse seed-dot grid (Field), braided lens-chains of waves (Loop), striped candles with flickering flames and wax drips (Tallow), pulsing blobs with a scrolling ECG trace (Pulse) and a marching-squares topographic contour map with a route and "you are here" ping (Atlas). The same functions render the hover preview, static mobile thumbnails and the large case-study canvas.
- Floating preview card: exponentially damped follow, horizontal velocity mapped to skewX and rotation, clip-path wipe between artworks using the Web Animations API.
- Full-screen case-study overlay: two-stage clip-path curtain (cover, swap content, reveal) via WAAPI, per-project colour themes from the palette, masked letter rise for the title, parallax numerals, focus management, inert/aria-hidden page, scroll lock with scrollbar compensation, keyboard next/previous/Escape and a queued close request.
- Eased (Lenis-style) scrolling: wheel events are intercepted and a damped scroll loop follows, re-syncing when the scroll is changed by keyboard, scrollbar or anchors; scroll velocity also speeds up and reverses the marquee.
- Split-text word masks and IntersectionObserver reveals, hairlines that draw in, count-up figures, auto-hiding difference-blend header and scroll-progress bar.
- Magnetic button (attraction radius, parallax inner label), letter-roll email link fitted to container width with JS, clipboard copy with toast (address is fictional).
- Procedurally generated canvas grain tile, ink/bone mode toggle persisted in localStorage, live Europe/Oslo clock, inline SVG textPath rotating badges, inline SVG Kern the dachshund easter egg.

==================== INTERACTION ====================
Desktop: move the pointer across the giant name to swell and thicken nearby letters; the custom cursor grows over links and reads VIEW over project rows. Wheel scrolling is eased; the header hides while scrolling down and returns on scroll up. Hover a project row to ink-fill it, dim its siblings and float its generative artwork on the cursor (it skews with speed and wipes between artworks); click or press Enter to open the case study through a vermilion curtain. In the overlay use Close, Escape, the Next project block or the left/right arrow keys; scroll inside it for the artwork, metadata, copy and statistics. The "Get in touch" disc is magnetic; clicking it or the huge email link copies the (fictional) address and shows a toast. The half-moon toggle in the header switches ink/bone mode. Type "kern" anywhere for a dachshund to trot across the screen. Tab order and visible focus outlines are provided, with a skip link. Touch and small screens: cursor effects and hover previews are off, rows show static artwork thumbnails, tapping a row opens the case study, the ghost pointer animates the hero type. prefers-reduced-motion: no loader, letter rise, ghost pointer, eased scrolling, marquee motion, skew or curtain animation; content appears immediately and overlays simply appear.
