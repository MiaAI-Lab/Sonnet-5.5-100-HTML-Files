==================== TITLE ====================
Nail & Thread

==================== DESCRIPTION ====================
A square walnut board (layered grain gradients, two SVG turbulence filters, vignette and top-left light) carries a ring of brass nails with individual drop shadows and engraved numbering. Silk threads join nail i to nail i x m (mod N) using additive blending on a transparent canvas laid over the wood, so overlaps flare into luminous glints. The multiplier m sweeps continuously, morphing between cardioid, nephroid and higher epicycloids while the curve name fades in beside a live brass plaque reading "y = x . m (mod N)" and a one-line explainer. A large knurled brass dial, nail-count and opacity sliders, three palettes (Silk, Ink on Paper, Neon), a needle-and-thread winding mode and an analytic gold envelope complete the workbench.

==================== TECHNIQUES ====================
- Three stacked canvases: nail shadows, additive thread layer (CSS screen or multiply blend), nail heads with pre-rendered radial-gradient brass sprites
- Fractional multiplier: each thread's far end is placed at angle 2*pi*(i*m mod N)/N, so the picture morphs continuously between integer maps
- Analytic envelope z(t) = (m e^(i(phi+t)) + e^(i(phi+m t))) / (m+1) drawn as a gold SVG path with a soft glow filter
- Wood built from repeating-linear-gradients plus two feTurbulence grain filters, inner bevel highlights and vignette
- Palette gradient along nail index; glow pass plus thin core pass per thread; thread alpha auto-scaled by nail count
- Sweep state machine: eased moves between pleasing integer stops with holds, ping-pong direction, curve names for epicycloids
- Draw-one-by-one mode with a moving SVG needle and partially drawn current thread
- Circular knurled dial (conic gradients) with square-root mapping for fine control at low m, engraved tick labels regenerated per nail count
- Brass plaque with screws, engraved-text shadows, old-style serif type
- Dirty-flag rendering so the canvases only redraw when something changes

==================== INTERACTION ====================
Drag the dial (or press Left/Right/Up/Down) to change m in 0.1 steps; manual changes pause the automatic sweep. Nail count slider (60 to 360) and thread opacity slider reshape the piece live. Palette chips switch between Silk, Ink on Paper and Neon (the board itself re-themes). Play/Pause toggles the sweep (Space), "Reveal envelope" (E) overlays the gold envelope, and "Draw threads one by one" (W) winds the threads sequentially with a needle. With prefers-reduced-motion the sweep starts paused and moves are shortened. Rendering pauses when the tab is hidden.
