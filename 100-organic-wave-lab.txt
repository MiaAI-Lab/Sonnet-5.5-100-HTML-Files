==================== TITLE ====================
Organic Wave Lab

==================== DESCRIPTION ====================
A soft, breathable design lab on a deep indigo (or warm cream) page whose background quietly tints toward the artwork's dominant colour under a film of grain. A large rounded stage renders live inline SVG in three modes: Blob (stacked, offset Catmull-Rom blob layers with gradient fills and screen or multiply blending), Wave (layered sinusoid bands like SVG dividers) and Rings (concentric distorted outlines). A glass control panel holds sliders for Complexity, Distortion, Speed, Layers, Blur and Grain, a seed field with dice and lock, a palette and gradient-stop editor with validated hex input, and a live code box showing the exact static SVG of the current frame with Copy and Download buttons. Up to six snapshots appear as clickable thumbnails. On mobile the panel becomes a bottom sheet.

==================== TECHNIQUES ====================
- Closed Catmull-Rom splines converted to cubic Bezier path data (and open splines for wave bands)
- Seeded multi-sine noise per point (three incommensurate sines with seeded phases) so shapes flow smoothly and reproducibly per seed
- One describe() function feeds the live DOM, the exported SVG string and the snapshot thumbnails, so the code box always matches the art
- Layered gradient fills at rotated angles, opacity ramps and mix-blend-mode screen (dark) or multiply (light)
- SVG feGaussianBlur and feTurbulence grain overlay; the export includes the blur filter definition
- Palette engine: five curated palettes, click-to-cycle gradient bar, 2 to 4 editable stops, strict #RRGGBB validation with inline feedback
- Page background tint smoothed toward the palette midpoint with a grain overlay canvas tile
- Blob-URL download and clipboard copy with a textarea fallback, all local
- Snapshot strip storing full state with generated thumbnail SVGs (unique gradient ids per thumbnail)
- Responsive bottom sheet with a handle button and aria-expanded, glass panel with backdrop blur

==================== INTERACTION ====================
Switch Blob, Wave or Rings at the top. Move any slider and the artwork and code update live. Type a seed or press the dice button (or R) to randomise shape and palette; the lock button keeps the shape and reshuffles colour only. Click the gradient bar to cycle palettes, click a chip to pick one, click a stop swatch to select it and type a hex value, use plus and minus to add or remove stops (2 to 4). Space pauses or resumes the morph, S saves a snapshot (click a thumbnail to restore it). Copy SVG and Download .svg export the current frame. The sun button toggles light and dark themes. On phones the panel slides up from the bottom handle. With prefers-reduced-motion the morph starts paused. Animation pauses when the tab is hidden.
