==================== PROMPT ====================
Design "GRV-16", a tactile hardware-style drum machine as a web instrument. Skeuomorphic device: matte charcoal body #1d1f24 with a brushed-metal top strip, orange accent #ff6a1a, cream silk-screened labels, 16 rubber-look step pads in a row (rounded squares with inner LED glow when active and a moving playhead), 8 track rows (Kick, Snare, Clap, Closed Hat, Open Hat, Tom, Rim, Cowbell) each with mute/solo mini buttons and a volume knob, big rotary knobs for Tempo (60–180), Swing and Master (drag to turn; wheel and keyboard supported), and a Play/Stop transport with LED. Sound: fully synthesised with WebAudio — kick (sine sweep + click), snare (noise + tone), clap (bursts of filtered noise), hats (high-passed noise plus metallic square oscillators), tom, rim, cowbell; precise look-ahead scheduling with audioContext.currentTime; per-step accent via right-click or long-press. Preset patterns (House, Boom-Bap, Trap, Afrobeat) and a Random fill; a small VU meter / oscilloscope on canvas. Present the device on a desk mat with soft shadows and a subtle vignette; on mobile the grid scrolls or rotates gracefully. Show a friendly "Tap to power on" overlay so audio starts on the first gesture; master volume default modest.

TECHNICAL REQUIREMENTS: Deliver one completely self-contained, standalone HTML5 file with all CSS inline in a <style> tag and all JavaScript inline in a <script> tag. No external dependencies of any kind: no CDN, no external fonts (system font stacks only), no external images, no external SVG files, no libraries, no network requests. It must work by simply opening the file in a browser, fully offline. It must be responsive from 360px phones to large desktops, validate as standard HTML5, respect prefers-reduced-motion, support mouse and touch input, and run without console errors. Hand-craft it as a premium, award-worthy piece of digital art with real, evocative copy (no lorem ipsum), a disciplined palette, careful typography, polished motion and delightful details.

==================== TITLE ====================
GRV-16 Groove Box

==================== DESCRIPTION ====================
A charcoal drum machine sitting on a teal felt desk mat with a stitched border, a wooden desk edge, a soft vignette and a pencil that jumps with the kick. The device has a brushed-metal top strip with the GRV-16 wordmark, an amber LED display (tempo, step, swing, pattern name) and a phosphor oscilloscope with a segmented VU meter; below it a knob cluster (large Tempo, Swing, Master), a Play/Stop key with beat LED, four pattern keys plus Random fill and Clear, and a sequencer of eight rows (Kick to Cowbell), each with M and S buttons, a small volume knob and sixteen rubber pads grouped in fours. Active pads glow orange from within, accented steps burn hotter with a white spark, and a playhead LED strip and lit column follow the beat. All eight voices are synthesised live with WebAudio. A friendly "Tap to power on" screen unlocks audio, boots the display and starts the House pattern at a modest level.

==================== TECHNIQUES ====================
- Skeuomorphic CSS: layered gradients, inset and drop shadows, brushed metal via repeating gradients, knurled knob caps from conic gradients, rubber pads with pressed states, screws, silkscreen type, and a generated felt-noise texture tile.
- Custom knob component built from pointer events with capture (vertical drag, Shift for fine control), wheel, and arrow / Page / Home / End keys, exposed as role="slider" with aria values, a drag tooltip and tick-ring SVG.
- Fully synthesised drums: sine-sweep kick with click, noise + two-oscillator snare, four-burst clap, persistent six-square metallic bank shared by closed and open hats (with hat choke), sweeping tom, dual-tone rim, two-square cowbell; tanh saturation, compressor, master gain with a squared curve for a modest default.
- Classic look-ahead scheduler (25 ms timer, 140 ms horizon, audioContext.currentTime) with swing applied to off-beat steps (50 to 75 percent), tempo read every step, and a queue that drives the visual playhead in sync with the audio clock.
- Pad editing: click toggles, drag paints, right-click or 460 ms long-press sets accent, keyboard (Enter/Space, A for accent, arrow navigation); previews the voice when placing a step.
- Mute/solo logic, four presets that also set tempo and swing, and a weighted "random fill" that respects each instrument's typical positions.
- Canvas oscilloscope with rising-edge trigger, glow pass and 12-segment VU; the desk pencil reacts to kick hits.
- Layout: a 1240 px design scaled to fit on desktop; below 900 px a stacked layout with a horizontally scrolling grid, sticky row labels and auto-following playhead.

==================== INTERACTION ====================
Tap "Tap to power on" to create the audio context; the display boots and House starts. Click, tap or drag across pads to draw a pattern; right-click or long-press a pad for an accent; M and S mute or solo a track; turn knobs by dragging up or down, with the wheel or with the keyboard. Tempo (60-180), Swing and Master update the display live. Play/Stop or the Space bar starts and stops. Pattern keys load House, Boom-Bap, Trap or Afrobeat with their tempo and swing; Random fill and Clear reshape the grid. On phones the grid scrolls sideways and follows the playhead unless you are scrolling it. With prefers-reduced-motion, pad flashes, pencil jumps and the boot animation are shortened or removed while the instrument stays fully functional.
