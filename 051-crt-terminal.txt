==================== TITLE ====================
ORACLE-9 Operator Console

==================== DESCRIPTION ====================
A beige 1987 terminal sits in a dark, warm room. Its curved tube (heavily rounded glass, inset shadows, a lens glare arc) shows amber phosphor text on brown-black with layered glow, red/cyan fringing, scanlines, an aperture mask, flicker, a slow rolling refresh bar, vignette and runtime-drawn dust and a faint thumbprint. The plastic front carries screws, an engraved brand plate, moulded vents, a power LED, a mains rocker, an audio switch, a knurled draggable brightness knob with tick marks, a stuck-on yellow note and a serial label. The tube powers on with a collapsing-beam animation, then types a BIOS sequence (memory counter, device checks whose [ OK ] flashes, a loading bar), clears, prints a block-letter ORACLE-9 logo and asks for an operator id (it auto-logs in as "guest" if you wait). A boxed main menu follows and a real shell with a block cursor: help, about, ls, cat (six fictional poems, story fragments and logs plus a forbidden secrets.enc), whoami, date, theme amber/green/white, matrix (falling glyph rain), fortune, ask (an oracle whose answers are stable per question), calc (recursive-descent parser, no eval), history, clear, sound, bright, reboot, menu, banner and a few easter eggs. On phones the bezel shrinks to a frame, the screen fills the width, and beige keycaps type commands for you.

==================== TECHNIQUES ====================
- Barrel-curved glass approximated with elliptical border-radius, deep inset box-shadows, a vignette, a glare arc and a lens gradient
- Layered text-shadow phosphor glow plus red/cyan sub-pixel fringing; repeating-gradient scanlines and an RGB aperture mask
- Flicker, rolling refresh band and screen glitch as CSS animations; power-on/off beam collapse animation
- Runtime canvas textures: plastic grain, dust motes, smudges, scratches and a thumbprint
- Plastic bezel from stacked gradients and shadows: brand plate, vent grille, LED glow, rocker, switch, knurled conic-gradient knob
- Queue-based typewriter engine with variable speed, bursts, punctuation pauses, skip-on-Enter and boot-phase cancellation
- Mirrored-input prompt: a transparent focused input drives a styled line with a true block cursor at the caret; history, tab completion (commands, files, arguments), Ctrl+L / Ctrl+C
- Safe recursive-descent calculator with operators, constants and functions, and precise error messages
- Matrix rain on canvas using theme colours; three phosphor themes changed with a brief signal glitch
- WebAudio key clicks (filtered noise) and 50/100 Hz hum, opt-in, master gain 0.22
- Design-size stage scaled to fit the viewport, and a compact phone layout with visualViewport-aware height and keycap shortcuts

==================== INTERACTION ====================
The console powers itself on at load; the mains rocker turns it off and on (rebooting). Press Enter, Space or click during boot to skip. At the login prompt type an id or press Enter (it types "guest" for you after a few seconds). Then type commands: help, about, ls, cat <file>, whoami, date, theme <amber|green|white>, matrix (press any key or tap to leave), fortune, ask <question>, calc <expression>, history, clear, sound on|off, bright <0-100>, reboot, menu, banner; a number 1-5 runs a menu entry. Up/Down recall history, Tab completes, Enter during typewriter output finishes it at once. Drag the knurled knob (or focus it and use arrow keys, Home, End, or the wheel) to change brightness; the audio switch enables keyboard clicks and hum. Click the screen to focus the input. On touch devices tap the screen to raise the keyboard or use the keycaps (help, ls, fortune, ask, matrix, clear). With prefers-reduced-motion flicker, the rolling bar and blink are removed and typing speeds up.
