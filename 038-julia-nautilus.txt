==================== TITLE ====================
Nautilus Fractal Explorer

==================== DESCRIPTION ====================
A full-screen deep-sea fractal explorer in the colours of a nautilus shell (abyss #03122b, petrol #0b4f6c, teal #2ec4b6, cream #fff1c1, amber #ff9f1c). The Mandelbrot set opens as a glowing shape on a navy field; Mandelbrot and Julia modes, four switchable palettes (Nautilus, Ember, Orchid, Ink), a guided Tour and a corner minimap sit in a hushed glass-panel interface with an italic serif title, mono coordinates and a subtle vignette and grain. Rendering is a two-pass WebGL pipeline: the first pass iterates the escape-time equation (up to 300 iterations, cardioid/bulb shortcut) and stores the smooth iteration count plus two orbit-trap values in an RGBA8 data texture; the second pass turns that data into colour with two-term cosine palettes fitted to the brief's stops, orbit-trap glow, bilinear reconstruction, a free 2×2 supersample and film grain, so palettes morph instantly and the colours drift slowly on their own even at rest. Interaction stays fluid through dynamic resolution plus progressive strip refinement, and a friendly "Precision horizon" note appears when float32 runs out of digits, after which the view sails back home. Without WebGL the same picture is drawn by a progressive low-resolution CPU renderer.

==================== TECHNIQUES ====================
- WebGL 1 two-pass renderer: escape-time pass writes smooth iteration count (16-bit packed into two 8-bit channels), point-trap and circle-trap values to RGBA8 textures; colourise pass decodes and shades every frame, so palette morphs and colour drift cost almost nothing.
- Smooth (continuous) iteration colouring, mu = n + 1 − log2(log2|z|), mapped through log-scaled mirrored cosine palettes; orbit-trap glow (point trap) and a circle-trap interior glow; main cardioid / period-2 bulb shortcut for interior pixels.
- Palettes are two-term cosine palettes a + b·cos(2π(c·t+d)) + e·cos(2π(f·t+g)) whose parameters were least-squares fitted to the exact brief stops (Nautilus) and to matching ramps for Ember, Orchid and Ink; slow sinusoidal phase drift, faster during the tour.
- Dynamic-resolution interaction (interactive frames at 0.25–1× scale driven by frame-interval feedback, no GPU read-backs) followed by progressive full-resolution refinement in scissored strips, optionally at 2× resolution for supersampling; nothing ever blocks the main thread.
- Navigation: pointer drag pan with inertia, wheel/pinch zoom anchored on the cursor with exponential smoothing, double-click dive, keyboard (arrows, +/−, R, M, P, T, H); Julia mode maps the whole screen to a Mandelbrot minimap frame so dragging morphs c live, with a Morph/Pan drag toggle.
- Tour uses van Wijk & Nuij smooth pan-zoom flight paths (zoom out, glide, zoom in) between Seahorse Valley, Elephant Valley, the Mini-brot and a self-chosen spiral called "The Nautilus" near (−0.74515, 0.11258), with animated place-name captions.
- Precision horizon: a dynamic depth limit from float32 ulp at the current centre (~2·10⁴ near the seahorse, ~5·10⁴ near the elephant valley); a note appears and the view flies gently home when the visitor pauses.
- Minimap rendered by the same shaders into a corner viewport with a DOM marker showing c (Julia) or the view rectangle (Mandelbrot); click/drag on it to choose c or recentre.
- CPU fallback: progressive 16→1 pixel block refinement of the same shading maths on a low-resolution canvas, with CSS grain and vignette.
- Glass panels with backdrop blur, safe-area insets, responsive layout down to 360px, reduced-motion handling.

==================== INTERACTION ====================
Mouse: drag to pan (with inertia), scroll to zoom toward the cursor, double-click to dive. Touch: drag to pan, pinch to zoom and pan together, double-tap to dive. Top bar: Mandelbrot / Julia toggle, four palette swatches, and a Tour button (starts an automatic voyage between four coordinates; any input stops it). In Julia mode a drag morphs the constant c live (the whole screen acts as a giant minimap; a Drag: Morph c / Pan switch, shift-drag, right-drag or two fingers pan instead), and the minimap crosshair follows c; in Mandelbrot mode clicking the minimap recentres the view. Keyboard: M mode, P next palette, T tour, R reset, H hide interface, arrows pan, + and − zoom. The bottom-left HUD shows re/im, zoom factor and iteration cap in mono; a pulsing dot signals progressive refinement. Reaching float32 precision shows the "Precision horizon" note and sails back to open water. prefers-reduced-motion: no colour drift or supersampling, flights become slower and inertia disappears, palette changes are instant.
