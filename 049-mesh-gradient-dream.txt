==================== TITLE ====================
Lucid — A Study in Colour

==================== DESCRIPTION ====================
A single fixed dreamscape sits behind a whole scrolling page: seven soft colour fields (five ordinary, one drawn with "screen", one with "soft-light") are painted on a small canvas, stretched over an oversized element and blurred by about 60px, then bent by an SVG feTurbulence + feDisplacementMap pair whose base frequency drifts slowly, so the edges of the fields flow like liquid. Each field follows its own Lissajous path (two incommensurate frequencies) and leans gently toward the pointer. A film-grain veil made from a tiny runtime-generated noise tile dances over everything. The hero word "lucid" is set in a soft serif italic and treated as glass: inside every letter a second canvas shows the same fields magnified 2.4x, unblurred and with faint caustic ripple rings, bent by a three-pass SVG displacement (one pass per colour channel, so the edges disperse into rainbow fringes); over that sits a backdrop-filter frost, an SVG lighting filter that gives bevelled specular edges (its light follows the pointer), an inner rim shade, a tinted drop shadow that only falls outside the letters, colour-fringed hairlines and a periodic sheen sweep. A floating pill switcher crossfades four moods (Calm, Electric, Sunset, Ink) over 1.2 s — every colour, ink, glass tint and shadow on the page is interpolated in JavaScript and written to CSS custom properties. Below the hero: a big serif statement with three facts, three "Effects" cards (Drift, Refract, Grain) each with a looping pure-CSS gradient demo, and a "Make your own" lab with four live sliders (blur, grain, speed, contrast), a generated CSS recipe that mirrors the current mood and settings, a Copy CSS button and a reset. The page sheds its heaviest filters automatically on software renderers or slow machines while keeping the same look.

==================== TECHNIQUES ====================
- Seven radial-gradient blobs drawn on a low-resolution 2D canvas (source-over, screen, soft-light) on slow Lissajous paths with elliptical, slowly rotating, breathing shapes
- CSS blur(60px) + contrast + saturate on an oversized canvas element, plus an animated SVG feTurbulence + feDisplacementMap organic warp
- Runtime-generated film-grain tile (tiny canvas to data URL) overlaid on the page, jittered with a stepped transform animation
- Glass wordmark: measured SVG text (canvas measureText fits the word to the viewport), clip-path text clipping of a magnified "lens" canvas and a backdrop-filter layer
- Three-channel chromatic displacement filter (feDisplacementMap x3 + feColorMatrix + feBlend screen) applied to the lens; caustic ripple rings drawn inside the lens
- SVG feSpecularLighting + fePointLight bevel driven by the pointer, inner edge shading, outside-only coloured shadow, screen-blended colour-fringe strokes and a clipped CSS sheen
- Mood tween: every palette colour, ink, glass, line, shadow and veil token is interpolated in JS with cubic easing over 1.2 s and written to CSS custom properties
- Pointer attraction with exponential falloff and spring easing; click/tap bloom and refraction pulse
- Effects demos in pure CSS: nested easeInOutSine translate animations forming an exact 3:2 Lissajous with a dotted trace, a backdrop-filter lens over stripes, and a clip-path wipe between clean and grained gradients
- Live CSS export (pre block + Clipboard API with execCommand and selection fallbacks) reflecting mood, blur, grain, speed and contrast
- Scroll-driven veil and header scrim, IntersectionObserver reveals, card tilt with cursor-following sheen
- Adaptive quality governor and software-renderer detection (lite mode bakes contrast and saturation into the palette and drops backdrop filters); optional #lite / #full hash to compare

==================== INTERACTION ====================
Move the pointer (or drag a finger) and the nearest colour fields drift toward it while the glass letters shift their refracted view and their highlights follow the cursor; click or tap anywhere to make the fields bloom, and click the word itself for a stronger refraction pulse. The floating pill at the bottom switches between Calm, Electric, Sunset and Ink (also keys 1-4), and the whole page — background, type, panels, sliders — crossfades in 1.2 s. Scroll to reveal the About statement, the three Effects cards (hover them for a subtle tilt and light) and the Make your own lab: drag the four sliders (blur, grain, speed, contrast) and the fixed background behind the page changes live; the CSS recipe updates beneath, Copy CSS puts it on the clipboard (with a friendly status message and fallbacks), Reset restores the defaults. The header gains a soft scrim once you scroll, and a small scroll cue sits at the foot of the hero. Everything is keyboard reachable with visible focus rings and aria-live announcements. With prefers-reduced-motion the drift slows to a crawl, the intro and reveals are shortened, the sheen, cue and card demos stop, and the page remains fully composed.
